## 0. ข้อจำกัดของโปรเจกต์
- ผู้พัฒนาคนเดียว + Claude (vibe code) → **เรียบง่าย, TypeScript ทั้งหมด, data-driven**
- เล่นฟรี, **Browser ก่อน** (PWA) → ห่อเป็นแอปด้วย Capacitor ภายหลังได้โดยใช้โค้ดเดิม
- เปิดที่ **จังหวัดเชียงใหม่** ก่อน → คาดว่าผู้เล่นจะโตขึ้นเรื่อยๆ จึงต้อง

  - ความเป็นส่วนตัวของคนแปลกหน้าต้องปลอดภัยตั้งแต่วันแรก

## 0.1 แผนที่โลกจริง (อัปเดต 2026-09-22)
- **พื้นหลังเป็นแผนที่จริง** (แบบ Pokémon GO): MapLibre GL + สไตล์ OpenFreeMap "liberty" เอียง 55° มีตึก 3D
  ปรับสีเป็นโทนเกม และ **ซ่อนป้ายชื่อร้าน/แบรนด์** — กล้องล็อกตามผู้เล่น (เลื่อนแผนที่ออกจากตัวไม่ได้)
- กล้องอิสระ: ลากนิ้วเดียว/คลิกซ้าย ซ้าย-ขวา = หมุน, ขึ้น-ลง = เอียง 0–75°; ถ่าง/ลูกกลิ้ง = ซูม 13–20;
  2 นิ้ว = หมุน+ซูม; 🧭 = กลับทิศเหนือ + มุมเอียง 55°
- สไปรต์ 16-bit (ตัวละคร, แลนด์มาร์ก) วาดโดย Phaser บน canvas โปร่งใส ทับตำแหน่งจริงด้วย `map.project()`
- ข้อมูลเกมเบื้องหลัง (ภูมิประเทศสำหรับมอนสเตอร์/เขตปลอดภัย, แลนด์มาร์ก) ยังถอดจาก vector tile z14 เดียวกัน
  (1 chunk = 256×256 ช่อง ~9 ม.) — ไม่ได้ใช้วาดแผนที่แล้ว
- ใช้ GPS จริงได้ทุกที่ ถ้าไม่มี GPS/ไม่อนุญาต → โหมดจำลองเริ่มที่ตำแหน่งล่าสุด หรือเชียงใหม่
- **ใช้ได้ทั่วโลก (2026-09-24):** หมุดทุกประเภทมาจากชั้น `poi` ของ OpenFreeMap (OpenMapTiles schema ข้อมูล OSM อัปเดตทุกสัปดาห์)
  ชื่อบนหมุดเป็นชื่อหมวดภาษาไทยทุกประเทศ · เวลาเกิดบอส/รีเซ็ตเควสใช้เวลาท้องถิ่นของเครื่องผู้เล่น
  · ร้านสะดวกซื้อเหลือ 1 หมุด/~270 ม. ที่อื่น 1 หมุด/~60 ม. (กันเมืองใหญ่รก) · สำรวจข้อมูลจริงด้วย `npx tsx tools/osm/probe-pois.mts`
- ยังแนะนำให้ **เปิดชุมชนผู้เล่นที่เชียงใหม่ก่อน** (ความหนาแน่นผู้เล่น) แม้แผนที่จะใช้ได้ทั่วโลก
- `tools/osm` (baker แบบ offline) เก็บไว้เป็นเครื่องมือสำรอง

## 0.2 ตัวละคร (อัปเดต 2026-09-23)
- **สร้างตัวละคร**: ชื่อ + เพศ ('male' | 'female') + ทรงผมตามเพศ (โหลดจาก `manifest.json` ไดนามิก ไม่ hard-code) + สีผม + สีผิว
  (เลิกมี "สีชุด" ตั้งแต่ 2026-09-24 — ชุดเป็นภาพวาดมือ ย้อมสีไม่ได้ ดู §5)
- **สไปรต์ตัวละคร (Avatar Layer Pack)**:
  - ขนาด Cell 48×64 px ตัวละครสูงจริง ~45 px, จุดอ้างอิงเท้า (Anchor) ที่ `(24, 58)` (Origin `0.5, 0.906`)
  - เรนเดอร์ด้วยการซ้อนเลเยอร์ Body (recolor สีผิว) + Outfit (ภาพสีจริง ห้าม recolour) + Hair (recolor ตาม tone ramp 6 ระดับ) พร้อมแคช offscreen canvas
  - ไฟล์ชุดตั้งชื่อตามเฟรมของ body: `outfit/<id>/<ชื่อไฟล์เดียวกับ frame.body>` — ใส่ชุดจาก pack แล้วจะไม่วาดเสื้อ/กางเกง/รองเท้าแบบ procedural ทับ
  - **ท่า**: เดินลง `walk_front` · เดินขึ้น `walk_back` · **ยืน `idle`** (6–10 เฟรมแล้วแต่ทรงผม หันหน้าเข้ากล้องอย่างเดียว) —
    ยืนนิ่งเกิน 300 ms เข้าท่ายืน เปลี่ยนเฟรมทุก 350 ms พอขยับกลับท่าเดินทันที (`IDLE_DELAY_MS` / `IDLE_MS` ใน `game/avatar.ts`)
  - **ฟันดาบ `slash`** (3 เฟรม: ง้าง / ฟัน / ตามแรง) ใช้ในฉากต่อสู้เมื่อพุ่งเข้าหาเป้าหมายด้วยสกิลระยะประชิด —
    เฟรมฟัน (index 1) ตรงกับจังหวะที่ดาเมจลง · เฟรมพวกนี้มีชั้นเพิ่ม `hand` (มือ ย้อมสีผิวเหมือนตัว) `weapon` (ดาบของ pack
    ใช้แทนอาวุธที่โค้ดวาด) `fx` (เส้นฟัน วาดหลังตัว) · ลำดับวาด: fx → body → outfit → hair → weapon → hand
  - หันหน้า 3/4 ไปทางขวาเป็นหลัก (เดินลง `walk_front`, เดินขึ้น `walk_back`, หันซ้ายใช้ `flipX`)
  - คุมผ่าน flag `USE_AVATAR_PACK` (เก็บสไปรต์ procedural 16×24 เดิมไว้เป็น fallback)
- **สเกลมอนสเตอร์**: ปรับสมดุลให้สอดคล้องกับตัวละครผู้เล่น (มอนสเตอร์ทั่วไป ~32–48 px, บอส ~56–64 px)

## 0.3 ระบบฟาร์มมอนสเตอร์บนแผนที่ (อัปเดต 2026-09-22)
- **EXP ได้จากการตีมอนสเตอร์เท่านั้น**
- **อัตรา EXP ปัจจุบัน = ×10** (`EXP_RATE` ใน `rules/progression.ts` คูณกับ `rollLoot`) — ปรับเลขนี้ที่เดียวคุมความเร็วเลเวลทั้งเกม
  เส้นโค้งเลเวลยังเป็น `100 × L^1.5` เหมือนเดิม · ที่ ×10 ขึ้นเลเวลทุก ~2–3 ตัว (ของเดิม ×1 = 20–30 ตัว) · Gold/ของดรอปไม่เปลี่ยน
  ⚠️ ตั้งไว้สูงเพื่อทดสอบเนื้อหาช่วงเลเวลสูง — ต้องทบทวนก่อนเปิดให้คนนอกเล่น
- **ยกเลิกระบบ Walk Session / นับก้าวทั้งหมด** (ไม่มีปุ่มเริ่มเดิน, ไม่มี Stat Point จากก้าว, ไม่มีความทนทานลดจากการเดิน)
  — ตัวละครยังขยับตาม GPS ตลอดเวลา: การเดินคือวิธีไปหามอนสเตอร์ ไม่ใช่แหล่งรางวัล
- **เร็วเกิน 20 กม./ชม. = ต่อสู้ไม่ได้** (อยู่ในรถ) เพื่อความปลอดภัยและกันการนั่งรถวนฟาร์ม
- **โหมดจำลองการเดิน = เครื่องมือทดสอบ** ปรับความเร็ว 1×–300× ได้ วาร์ปด้วยคลิกขวา/กดค้างบนแผนที่ หรือปุ่ม 📍 (กลับคูเมือง) และได้รับยกเว้นการเช็กความเร็ว
  ⚠️ **ต้องปิดโหมดจำลองสำหรับผู้เล่นจริงก่อนเปิดเกม** (ไม่งั้นโกงเดินจากบ้านได้)
- มอนสเตอร์ **มองเห็นบนแผนที่** (แบบ Pokémon GO) — ช่องละ ~110 ม., สุ่ม 6 ครั้ง/ช่อง โอกาส 60% (~3.6 ตัว/ช่อง)
  จุดที่ตกบนตึก/เขตปลอดภัยจะลองย้ายไปจุดใกล้เคียงอีก 3 ครั้งก่อนตัดทิ้ง; แสดงสูงสุด 60 ตัวที่ใกล้ที่สุดในรัศมี ~330 ม.
- **Deterministic**: `hash(ช่อง, รอบเวลา 5 นาที, ช่วงเลเวล 5 เลเวล)` → ผู้เล่นเลเวลใกล้กันเห็นตัวเดียวกันที่เดียวกัน, สุ่มใหม่เพื่อโกงไม่ได้, ไม่ต้องมีเซิร์ฟเวอร์
- **รัศมีเล่น 120 ม.** (วงสีส้มบนแผนที่): แสดงเฉพาะมอนสเตอร์ในวง และ **แตะตัวไหนก็สู้ได้ทันที** — ไม่ต้องเดินเข้าไปทีละตัว
  ⚠️ ข้อแลกเปลี่ยน: ยืนกับที่ฟาร์มได้ ~15–20 ตัว/5 นาที ถ้าง่ายเกินไป ให้ยืดรอบเกิดใหม่ (15–30 นาที) แทนการลดรัศมี
- ขนาดสไปรต์ย่อ-ขยายตามซูมแผนที่; ซูมเริ่มต้น 16.6 ให้เห็นทั้งวงบนมือถือ
- **Auto Hunt (🤖 AUTO)**: วนเลือกมอนสเตอร์ในวงที่ใกล้สุด → สู้อัตโนมัติ 4× → ปิดหน้าผลเอง → ตัวถัดไป
  - ข้ามมอนสเตอร์ที่สูงกว่าผู้เล่นเกิน 1 เลเวล, HP < 30% ใช้ยา HP ให้ ถ้ายาหมด/ตาย/อยู่ในรถ → หยุดเอง; ไม่มีเป้า → รอรอบเกิดใหม่
  - ⚠️ ร่วมกับรัศมี 120 ม. = เปิดจอทิ้งไว้เลเวลขึ้นเอง → **ต้องมีเซิร์ฟเวอร์ตรวจ/จำกัดก่อนเปิดสาธารณะ** (กันบอท 24 ชม.)
- ไม่เกิดบนตึก วัด โรงเรียน โรงพยาบาล; ชนิดตามภูมิประเทศ (ถนน/เมือง/เขียว/น้ำ); เลเวลไม่เกินช่วงของผู้เล่น
- สีเลเวล: เขียว = ง่าย, เหลือง = พอดี, แดง = อันตราย
- ฆ่าแล้วหายจนกว่าจะถึงรอบ 5 นาทีถัดไป (เก็บต่อผู้เล่น)
- Novice passive เปลี่ยนเป็น **EXP จากมอนสเตอร์ +10%** จนถึง Lv.10
- โค้ด: `packages/shared/src/rules/spawns.ts`, `apps/game/src/game/spawns.ts`

## 1. Core Loop
```
เดินจริง (Walk Session) → ก้าว → EXP + Stat Points
   → เจอมอนสเตอร์ระหว่างทาง → สู้ (ATB) → ดรอป/Gold
   → แลนด์มาร์ก → บอส (เดี่ยว / ปาร์ตี้ / Async World Boss)
   → Home Base: ฝากเงิน ซ่อม ปรุงยา → อัป Build → เดินต่อ
```

## 2. Stats (6 ค่า)
| Stat | ผลหลัก |
|---|---|
| STR | ATK กายภาพ, น้ำหนักกระเป๋า |
| AGI | ความเร็ว ATB, Evasion |
| VIT | HP, DEF |
| INT | MATK, MP, MDEF |
| DEX | ATK ระยะไกล, Hit, Crit เล็กน้อย (Ranger) |
| LUK | Crit, Drop Rate |

- เริ่มต้นทุก Stat = 5 (ไม่นับใน % Mutation)
- Level up: **+5 Stat Points**
- เดิน: **ทุก 5,000 ก้าว = +1 Stat Point** (สูงสุด 4 แต้ม/วัน)
- สูตรค่าพลังย่อยทั้งหมด: `packages/shared/src/rules/stats.ts`
  - HP = 100 + VIT×15 + Lv×12 · ATK = STR×3 + DEX + Lv×2 (+DEX×2 สำหรับ Ranger) · DEF = VIT×1.5

## 3. Level & EXP
- ~~เดิน 1 ก้าว = 1 EXP~~ → **ยกเลิก**: EXP มาจากมอนสเตอร์เท่านั้น (ดู 0.3)
- EXP ที่ต้องใช้ขึ้นจาก Lv.L → L+1 = `floor(100 × L^1.5)`
- Level Cap เปิดตัว: **50**
- เป้าหมายจังหวะเกม: Lv.10 ≈ 3–4 วัน (5,000 ก้าว/วัน + ต่อสู้), Lv.20 ≈ 2 สัปดาห์

## 4. ~~Walk Session~~ (ยกเลิกแล้ว — ดู 0.3; เก็บไว้เป็นประวัติการออกแบบ)
Browser นับก้าวเบื้องหลังไม่ได้ → ผู้เล่นกด **▶ เริ่มเดิน**
- ใช้ Screen Wake Lock + โหมดจอมืดประหยัดแบต
- ระยะจาก GPS → ก้าว (**1 km ≈ 1,300 ก้าว**)
- **ความเร็ว > 20 km/h = ไม่นับ** (นั่งรถ) และจอเตือน "อย่าเล่นขณะขับขี่"
- ส่งจุด GPS เป็นชุดให้เซิร์ฟเวอร์ตรวจ (ความเร็ว, การกระโดดตำแหน่ง, accuracy) ก่อนให้รางวัล

## 5. การเริ่มเกม (Naked Dilemma) — อัปเดต 2026-09-23
รวมเข้าไปใน**หน้าสร้างตัวละคร** (ไม่มีหน้าเลือก A/B แยกแล้ว): ทุกคนได้ **งบ 500 Gold** แล้วเลือกเองว่าจะใส่อะไร
ชิ้นไหนใส่ = หักราคาชิ้นนั้น · ชิ้นที่ไม่ใส่ = เก็บเป็นทอง (`rules/starter.ts`, `STARTER_GEAR` ใน `data/items.ts`)

**ช่องสวมใส่มี 4 ช่องเท่านั้น (อัปเดต 2026-09-23): ชุด · หัว · เครื่องประดับ · อาวุธ** (`EQUIP_SLOTS`)
- ไม่มีช่องรองเท้า/มือรองแล้ว — **รองเท้ามากับชุด** · ไม่มีโล่ = ไม่มีโบนัสบล็อก +15% จากโล่
- ของเดิมถูกแปลงอัตโนมัติ (`LEGACY_ITEMS`): รองเท้าวิ่ง → เครื่องรางนักวิ่ง (AGI+8), โล่อีจีส → จี้อีจีส (DEF+40 VIT+6), รองเท้าแตะ → คืน 50 Gold

รวมเสื้อ กางเกง รองเท้า ปลอกแขน ในไฟล์เดียว ใช้ได้ทั้งชายและหญิง · **ย้อมสีไม่ได้** (เลิกมี "สีเสื้อ" ในหน้าสร้างตัวละคร) —

## 8. การต่อสู้ — Party Auto Turn-Based (แบบ Pockie Ninja) — อัปเดต 2026-09-22
**รายละเอียดเต็ม: [`docs/COMBAT_SPEC.md`](COMBAT_SPEC.md)** (แทนระบบ ATB เดิมทั้งหมด)
- ต่อสู้อัตโนมัติทั้งหมด เป็นรอบ เรียงตาม Speed (เสมอกันใช้ทอยตอนเริ่ม)

## 8C. เอฟเฟกต์ต่อสู้ & เสียง (อัปเดต 2026-09-23)
- **เอฟเฟกต์เป็น pixel art เท่านั้น** (sprite sheet จาก `pixel-art/fx/build.py`, 48×48/เฟรม, ขยายเป็นจำนวนเต็มเท่า) — เป็นงานแสดงผลล้วน ไม่แตะกติกา
- กติกาเลือกเอฟเฟกต์ (อัตโนมัติจากข้อมูลสกิล ไม่ต้องกำหนดรายสกิล):
  - สกิลเวท (ดาเมจ MAGIC) หรือสกิลสนับสนุน → วงเวทใต้เท้าผู้ร่าย (ศักดิ์สิทธิ์ = ทอง, ไฟ = ส้ม, อื่น ๆ = ม่วง)
  - สกิลเวท/สกิลยิงไกล (`ranged`) → กระสุนตามธาตุบินไปหาเป้า แล้วค่อยแสดงดาเมจ (ยิงไกลกายภาพ = ลูกธนู)
  - ตีโดน → เอฟเฟกต์ตามธาตุ · ธาตุปกติ: ประชิด = รอยฟัน, อื่น ๆ = กระแทก · คริ = ดาวแตก + จอสั่น · บล็อก = โล่
  - สถานะ: มึน = ดาววน, แข็ง = น้ำแข็ง, พิษ = ฟองเขียว, ไฟไหม้ = ไฟ, เลือดไหล = รอยฟันแดง, ช้า/รัด = ดีบัฟ, ยั่วยุ = บัฟ
  - ฮีล/ฟื้นฟู/ยา = แสงเขียว (ยา MP = แสงฟ้า), ตาย = ควัน, บอสเปลี่ยนเฟส = วงเวทไฟใหญ่
- **เสียงสังเคราะห์สดด้วย Web Audio** (`apps/game/src/game/audio.ts`) — ไม่มีไฟล์เสียง ไม่ติดลิขสิทธิ์
  - เพลง (`apps/game/src/game/music.ts`) เครื่องดนตรีสังเคราะห์แนว orchestral + reverb, วน 32 ห้อง, เปลี่ยนเพลงแบบ crossfade:
    - **แผนที่** — วอลทซ์เมืองแบบเกม MMO คลาสสิก (ref แนวเพลง: Theme of Prontera ของ RO — อ้างอิงแค่สไตล์ ทำนอง/คอร์ดแต่งใหม่ทั้งหมด):
      G major 3/4 138 bpm, โอโบ/ฟลุตร้องทำนอง + เครื่องสายดีด "ตุ้ม-ชะ-ชะ" + ฮาร์ป + เซเลสตา + แทมบูรีน, 40 ห้อง (A1 A2 B A3 + ช่วงพักฮาร์ป)
    - **ในบ้าน** — แนว VGM / New Age / Ambient: D major 76 bpm, pad เครื่องสาย + ฮาร์ป + เซเลสตา + ฟลุต
      โครง 4 ท่อน (รุ่งเช้า → เดินเล่น → สดใส → พัก) ไม่มีกลอง
    - **คุมธีมเดียวกันทั้งเกม**: ต่อสู้/บอสใช้วงเดียวกับเมือง (โอโบ ฟลุต เครื่องสายดีด ฮาร์ป เซเลสตา แทมบูรีน) อยู่คีย์ E minor
      (คีย์พี่น้องของวอลทซ์ G major) จังหวะ 6/8 = วอลทซ์ที่เร่งเป็นการบุก และธีม A เปิดด้วยทำนองขึ้นของวอลทซ์ในแบบไมเนอร์
    - **ต่อสู้** — 6/8 (จุดโน้ตตัวดำ = 100), เครื่องสายควบม้า + กลองมือ/แทมบูรีน, 40 ห้อง: A1 โอโบ → B ฟลุต (บันไดเสียง G major แบบเพลงเมือง)

    - **บอส** — E harmonic minor 6/8 (จุดโน้ตตัวดำ = 88), วงเดิม + คณะประสานเสียง + เครื่องสายต่ำ + กลองหนัก (เมื่อมีบอสในเวฟใดก็ได้)
    - จบการต่อสู้หยุดเพลง → **ชนะ = fanfare orchestral** (ฮาร์ปไล่ขึ้น → แตรเรียก → คอร์ด D major ใหญ่ + ไทโกะ/ฉาบ/เซเลสตา ~3.5 วิ) · แพ้ = jingle สั้น

  - เสียงเอฟเฟกต์จำกัดความถี่ต่อชนิด (45 ms) กันเสียงแตกตอนเร่งความเร็ว

## 8B. ปาร์ตี้ & ดันเจี้ยน (อัปเดต 2026-09-22)
- **ปาร์ตี้** สูงสุด 3 คน (`PARTY_MAX`) ชวนได้เมื่ออยู่ห่างกัน ≤ 200 ม. (`PARTY_RANGE_M`) — เกมเดินจริง ต้องมาเจอกันจริง
  - หัวหน้าชวน/เชิญออก/เปิดดันเจี้ยน · หลุดเน็ตหรือรีโหลดยังอยู่ในปาร์ตี้ 30 วิ · หัวหน้าออก → คนถัดไปเป็นหัวหน้า
  - **สายจูง (leash)**: เดินห่างจากสมาชิกทุกคนเกิน 200 ม. → เตือน แล้วหลุดปาร์ตี้ถ้าเกิน 10 วิ (กัน GPS กระตุก)
    ปาร์ตี้ 2 คนแยกกัน = ยุบปาร์ตี้ · ระหว่างต่อสู้ไม่นับ (`rules/party.ts` isolatedMembers)
  - สมาชิกชื่อสีเขียว 👥 บนแผนที่
- **ตีมอนบนแผนที่ = สู้ด้วยกัน**: ใครในปาร์ตี้แตะมอน (หรือ Auto Hunt) สมาชิกที่อยู่ใกล้ ≤ 200 ม. และว่างอยู่ถูกดึงเข้าสู้ด้วยอัตโนมัติ
  - HP มอน × n^0.6 (ATK เท่าเดิม) → สู้เร็วกว่าและปลอดภัยกว่าไปคนเดียว · EXP เต็มทุกคน · มอนตัวนั้นหายจากแผนที่ของทุกคน
  - ปาร์ตี้สู้ด้วยกันกดหนีไม่ได้ · ไม่มีสมาชิกอยู่ใกล้ = สู้คนเดียวตามปกติ (ไม่ต้องรอเซิร์ฟเวอร์)
- **ดันเจี้ยน (instance)** เปิดจากแผง 👥 ได้ทุกที่ เล่นคนเดียวหรือเป็นปาร์ตี้ — ข้อมูลใน `data/dungeons.ts`
  - ตรอกหมาผี (Lv.1+, แนะนำ 3–8) · โกดังพญาก็อบลิน (Lv.8+, 10–15) · ปั๊มร้างยามค่ำ (Lv.16+, 18–25)
  - พฤกษาอสูร (Park Treant) แนะนำ 4–8 คน = Raid รอปาร์ตี้ใหญ่/Mercenary ยังไม่เปิด
  - **ทั้งปาร์ตี้ต้องเข้าด้วยกัน และทุกคนต้องกด "ยอมรับ" ภายใน 20 วิ** — มีคนปฏิเสธ/ไม่ตอบ = ยกเลิก
  - ทุกคนต้อง: ออนไลน์ ไม่ได้กำลังสู้ อยู่ใกล้หัวหน้า ≤ 200 ม. และเลเวลถึง ไม่งั้นหัวหน้าเปิดไม่ได้ (บอกเหตุผล)
- **การซิงก์**: เซิร์ฟเวอร์รวบ setup ของทุกคน แล้วส่ง (dungeonId, seed, entrants) ชุดเดียวกันให้ทุกเครื่อง
  ทุกเครื่องจำลองการต่อสู้เองได้ผลเหมือนกันทุกเทิร์น (เอนจิน deterministic) — ไม่ต้องสตรีมเทิร์น เน็ตหลุดกลางทางก็เล่นจบได้
- **สเกลบอสตามจำนวนคน** แบบไม่เป็นเส้นตรง: HP × n^0.6 / (recMax+1) → ไปหลายคนได้เปรียบเสมอ
  (จำลอง: ปั๊มร้าง Knight เดี่ยว ~15% · Knight+Cleric ~64% · 3 คน ~90%)
- **ยาของใครของมัน** (ดื่มอัตโนมัติจากกระเป๋าตัวเอง) · **ของดรอปส่วนตัว** (แต่ละคนทอยเอง ไม่แย่งกัน) · EXP เต็มทุกคน
  ปาร์ตี้ชนะแต่ตัวเองหมดสติ = ได้รางวัล ไม่โดนโทษตาย · ปาร์ตี้แพ้ = โทษตายทุกคน
- ⚠️ ช่วง LAN: เซิร์ฟเวอร์เชื่อ setup จาก client — ก่อนเปิดจริงต้องสร้าง stat ฝั่งเซิร์ฟเวอร์จากบัญชี และให้เซิร์ฟเวอร์รันผลเองเพื่อแจกรางวัล

## 9. ความตายและอุปกรณ์
- **ทุกการต่อสู้ใหม่เริ่มด้วย HP/MP เต็ม** (อัปเดต 2026-09-25) — ไม่มี HP ค้างจากไฟต์ก่อน, หลังจบไฟต์ (ชนะ/แพ้/หนี) กลับมาเต็มเสมอ ·
  ยาที่ดื่มระหว่างไฟต์ยังหายจริง · ดันเจี้ยน/ประตูมิติหลายเวฟ: HP/MP **ต่อเนื่องระหว่างเวฟในรอบเดียวกัน** (ความยากของดันเจี้ยนอยู่ตรงนี้)
  ผลข้างเคียง: โรงพยาบาล/เขตศักดิ์สิทธิ์/เตียงในบ้าน/ฟื้นฟูตามเวลา ไม่มีอะไรให้ฟื้นแล้ว (ปุ่มขึ้น "HP/MP เต็มอยู่แล้ว") — รอออกแบบบทบาทใหม่
- ตาย: **Durability ชุดทั้งหมด = 0** (Naked State) + เสีย **20% ของ Gold ที่ถืออยู่** — Gold ที่ฝาก Home Base ปลอดภัย, **ไม่ลด EXP** (ไม่ต้องฟื้น HP แล้ว — ไฟต์ถัดไปเต็มเอง)
- **Durability ลดเมื่อตายเท่านั้น** (อัปเดต 2026-09-24) — ชนะหรือหนีไม่ลดเลย (`durabilityAfterBattle()` ใน `rules/economy.ts`)
  เลิกระบบ "ลด 1 ทุกการต่อสู้" และ "ลดตอนเดิน / อากาศร้อน" แล้ว · ตีบอสโลกแล้วหมดแรงนับเป็นหนี ไม่ใช่ตาย ของไม่พัง
- Rarity 5 ระดับ: Common/Uncommon/Rare/Epic/Legendary = ออปชันสุ่ม 0/1/2/3/4

  ชุด/หมวก/อาวุธใหม่แสดงบนตัวละครด้วย (`game/gear.ts`)

## 15. เทคโนโลยี
```
apps/game         Phaser 3 + TypeScript + Vite (PWA)          → Vercel/Netlify
packages/shared   กฎเกม + ข้อมูล (ใช้ร่วมทั้ง client และ server)
supabase/         Postgres + PostGIS, Auth, Realtime, Edge Functions (server-authoritative)
tools/osm         script ดึง OSM เชียงใหม่ → 8-bit tilemap + landmarks (static)
```
- ขยายจังหวัดใหม่ = รัน `tools/osm` กับ bounding box ใหม่
- Scale: Supabase Pro รองรับหลักหมื่นคน ถ้าเกินค่อยแยก Realtime server
