# ก้าวข้ามมิติ: Pixel Walker — Master Spec (Decided v1.0)

> เอกสารนี้คือ **แหล่งความจริงเดียว (single source of truth)** รวมจาก `docs/source/` ทั้ง 3 ฉบับ
> และการตัดสินใจทั้งหมดในการคุยออกแบบ 2026-09-22 ถ้าขัดกับเอกสารเก่า ให้ยึดฉบับนี้
> ตัวเลขทั้งหมดอยู่ในโค้ดที่ `packages/shared/src/data` และ `packages/shared/src/rules` — แก้ที่นั่นที่เดียว

---

## 0. ข้อจำกัดของโปรเจกต์
- ผู้พัฒนาคนเดียว + Claude (vibe code) → **เรียบง่าย, TypeScript ทั้งหมด, data-driven**
- เล่นฟรี, **Browser ก่อน** (PWA) → ห่อเป็นแอปด้วย Capacitor ภายหลังได้โดยใช้โค้ดเดิม
- เปิดที่ **จังหวัดเชียงใหม่** ก่อน → คาดว่าผู้เล่นจะโตขึ้นเรื่อยๆ จึงต้อง
  - **Server-authoritative**: รางวัล/EXP/ดรอป คำนวณที่เซิร์ฟเวอร์เท่านั้น
  - ความเป็นส่วนตัวของคนแปลกหน้าต้องปลอดภัยตั้งแต่วันแรก

## 1. Core Loop
```
เดินจริง (Walk Session) → ก้าว → EXP + Stat Points
   → เจอมอนสเตอร์ระหว่างทาง → สู้ (ATB) → ดรอป/Gold
   → แลนด์มาร์ก → บอส (เดี่ยว / ปาร์ตี้ / Async World Boss)
   → Home Base: ฝากเงิน ซ่อม ปรุงยา → อัป Build → เดินต่อ
```

## 2. Stats (6 ค่า)
| Stat | ผลหลัก |
|---|---|
| STR | ATK กายภาพ, น้ำหนักกระเป๋า |
| AGI | ความเร็ว ATB, Evasion |
| VIT | HP, DEF |
| INT | MATK, MP, MDEF |
| DEX | ATK ระยะไกล, Hit, Crit เล็กน้อย (Ranger) |
| LUK | Crit, Drop Rate |

- เริ่มต้นทุก Stat = 5 (ไม่นับใน % Mutation)
- Level up: **+5 Stat Points**
- เดิน: **ทุก 5,000 ก้าว = +1 Stat Point** (สูงสุด 4 แต้ม/วัน)
- สูตรค่าพลังย่อยทั้งหมด: `packages/shared/src/rules/stats.ts`
  - HP = 100 + VIT×15 + Lv×12 · ATK = STR×3 + DEX + Lv×2 (+DEX×2 สำหรับ Ranger) · DEF = VIT×1.5

## 3. Level & EXP
- เดิน **1 ก้าว = 1 EXP** (Novice ได้ +10% จนถึง Lv.10)
- EXP ที่ต้องใช้ขึ้นจาก Lv.L → L+1 = `floor(100 × L^1.5)`
- Level Cap เปิดตัว: **50**
- เป้าหมายจังหวะเกม: Lv.10 ≈ 3–4 วัน (5,000 ก้าว/วัน + ต่อสู้), Lv.20 ≈ 2 สัปดาห์

## 4. Walk Session (ข้อจำกัดของ Browser)
Browser นับก้าวเบื้องหลังไม่ได้ → ผู้เล่นกด **▶ เริ่มเดิน**
- ใช้ Screen Wake Lock + โหมดจอมืดประหยัดแบต
- ระยะจาก GPS → ก้าว (**1 km ≈ 1,300 ก้าว**)
- **ความเร็ว > 20 km/h = ไม่นับ** (นั่งรถ) และจอเตือน "อย่าเล่นขณะขับขี่"
- ส่งจุด GPS เป็นชุดให้เซิร์ฟเวอร์ตรวจ (ความเร็ว, การกระโดดตำแหน่ง, accuracy) ก่อนให้รางวัล

## 5. การเริ่มเกม (Naked Dilemma)
หน้าแรกหลังสร้างตัวละคร เลือก 1 ทาง (ครั้งเดียว):
- **A Standard Start:** เสื้อผ้าฝ้าย (DEF+2), ดาบไม้ (ATK+3), ยา HP ×5, 50 Gold
- **B Naked Challenge:** ชุดชั้นใน 8-bit, **500 Gold**

## 6. คลาส
- เริ่มเป็น **Novice** → **Class Trial ที่ Lv.10** ณ "วิหารแห่งการทดสอบ" (สวนสาธารณะ) ด่านเดี่ยว → เลือกได้ **ครั้งเดียว**
- Knight (VIT), Sorcerer (INT), Assassin (AGI/STR), Cleric (INT/VIT), Ranger (DEX)
- Passive และสกิลตาม PDF — ข้อมูลอยู่ที่ `data/classes.ts`, `data/skills.ts`

## 7. Extreme Mutation (ปรับสมดุลแล้ว)
- เงื่อนไข: **Level ≥ 20** และ **Stat เดียว ≥ 80%** ของแต้มที่ลงเองทั้งหมด
- เป็น **Awakening ซ้อนบนคลาส**: คงสกิลคลาสไว้ แต่ **Passive ประจำคลาสถูกแทนด้วย Passive Mutation** + ได้ฉายา + Aura
- ตรวจแบบสด: ถ้ารีเซ็ตแต้มจนต่ำกว่า 80% → สูญเสีย Mutation
- ค่าที่ปรับจาก PDF (กันเกมพัง):
  - Pure Tank: ลดดาเมจกายภาพ **90%** (ไม่ใช่ 0) + สะท้อน 30% True Damage + บล็อกท่าไม้ตายบอสได้ 1 ครั้ง/การต่อสู้ | ATK = 1
  - Pure Speed: Evasion 85% (สกิลบอสหลบได้ 50%), ความเร็ว ATB ×2 | HP Max ×0.2
  - Pure Mage: เวท +400%, ไม่มี Cooldown แต่ **MP ×3** | DEF = 0, Evasion = 0
  - Pure Strength: 15% สังหารมอนสเตอร์ทั่วไปใน 1 hit (ไม่มีผลกับบอส), น้ำหนัก +1,000 kg | ATB ช้า 50%, MP ×2
  - Pure Luck: Rare Drop ×5, 50% รอดตายที่ HP 1 + อมตะ 3 วิ (1 ครั้ง/การต่อสู้) | **ตัด Gold Jackpot ×100** (ทำลายเศรษฐกิจ)
  - Pure DEX (เพิ่มใหม่ ให้ Ranger มีสาย): Crit 100% จากระยะไกล | ATK ระยะประชิด = 1

## 8. การต่อสู้ — ATB (Active Time Battle)
- เกจ ATB เติมตาม Speed → เต็มแล้วเลือกคำสั่ง (โจมตี / สกิล / ไอเทม / หนี)
- สกิลมี Cooldown เป็นวินาทีตาม PDF, "ระยะ X ช่อง" = ช่องบนกริดต่อสู้ 1 มิติ
- มี **Auto Battle** สำหรับมอนสเตอร์ทั่วไป (เล่นระหว่างเดินได้)
- สูตรลดดาเมจ: `dmg = raw × 100 / (100 + DEF)` ขั้นต่ำ 1 — สเกลได้ดีทุกเลเวล
- เซิร์ฟเวอร์ใช้ seed เดียวกับ client → จำลองผลซ้ำเพื่อตรวจสอบได้ (deterministic)
- **มอนสเตอร์ระหว่างทางเป็นแบบเลือกเอง**: แจ้งเตือน "มอนสเตอร์ปรากฏ! [สู้] [ข้าม]" อยู่ 90 วินาที — ไม่บังคับเข้าฉากต่อสู้ขณะเดิน (ความปลอดภัยตอนข้ามถนน)

## 9. ความตายและอุปกรณ์
- ตาย: **Durability ชุดทั้งหมด = 0** (Naked State) + เสีย **20% ของ Gold ที่ถืออยู่** — Gold ที่ฝาก Home Base ปลอดภัย, **ไม่ลด EXP**
- Durability ลดขณะต่อสู้และเดิน (ร้อน > 35°C ลด ×1.5)
- Rarity 5 ระดับ: Common/Uncommon/Rare/Epic/Legendary = ออปชันสุ่ม 0/1/2/3/4

## 10. แลนด์มาร์กและบอส (ข้อมูลจาก OpenStreetMap)
| หมวด (OSM tag) | ในเกม |
|---|---|
| `shop=convenience` | ดันเจี้ยนร้านสะดวกซื้อ — **Convenience Goblin King** Lv.10, respawn 2 ชม. |
| `amenity=fuel` | **Octane Overlord** Lv.20, respawn 4 ชม. + **ร้านตีเหล็ก (Outpost)** ปิดเมื่อบอสเกิด |
| `leisure=park` (ใหญ่) | **Ancient Park Treant** Lv.30 — Async World Boss + วิหารแห่งการทดสอบ |
| แลนด์มาร์กเชียงใหม่ | บอสเฉพาะเมือง (ประตูท่าแพ, คูเมือง, นิมมานฯ, ม.ช., ดอยสุเทพ) — Phase 3 |

- บอสปรากฏเมื่อเข้าใกล้ **50 m**
- **ไม่ใช้ชื่อแบรนด์จริง** ในเกม (เสี่ยงเครื่องหมายการค้า) — ใช้ชื่อหมวด
- **ไม่เกิดมอนสเตอร์/บอสที่วัด โรงเรียน โรงพยาบาล สถานที่ราชการ**
- **Async World Boss:** HP รวม คงอยู่ 24 ชม. ใครแวะมาตีก็ได้ HP ลดร่วมกัน ปราบได้ → ทุกคนที่มีส่วนได้ของตามสัดส่วน — แก้ปัญหาคนไม่พร้อมกัน
  - ตีได้ครั้งละ **60 วินาที** และ **1 ครั้ง/30 นาที/คน**
  - ถูกบอสโลกตีจนหมด HP = **"ถูกตีกระเด็น"** ไม่มีบทลงโทษความตาย (ต้องการให้คนแวะช่วยกันตี ไม่ใช่กลัว)
- บอส (ยกเว้นบอสโลก) ปรับตามจำนวนคนในปาร์ตี้: HP × `party/(recMax+1)` (ขั้นต่ำ 20%), ATK × `0.6 + 0.4 × hpScale`
- ปรับสมดุลจาก PDF ด้วยการจำลอง (`balance.test.ts`): Goblin King ATK 120→105, Octane Overlord ATK 280→240 / DEF 150→110
  - เป้าหมาย: Lv.10 ตีคนเดียว ~60% ชนะ, Knight Lv.12 ~100%, Knight Lv.20 vs Octane ~50%
- Aggro/Loot ตาม PDF หัวข้อ 6.2

## 11. Home Base & Outposts
- Home Base 1 หลัง: ฝาก Gold/ไอเทม, ปรุงยา, ซ่อมราคาถูก — ย้ายได้ทุก 30 วัน หรือใช้ "โฉนด"
- **Home Base = Safe Zone อัตโนมัติ** รัศมี 200 m: ตัวละครไม่ปรากฏบน Radar ภายในรัศมีนี้
- Night Event (22:00–04:00) เกิด **ที่ Home Base** (ป้องกันบ้าน) — **ไม่ให้รางวัลการออกไปเดินกลางดึก**

## 12. Player Radar (ปลอดภัยสำหรับคนแปลกหน้า)
| ใคร | เห็นอะไร |
|---|---|
| เพื่อน (ยืนยันทั้งสองฝ่าย) / คนในปาร์ตี้ | ตำแหน่งสด (ยกเว้นใน Safe Zone / Ghost Mode) |
| คนแปลกหน้า ที่แลนด์มาร์กเดียวกัน | ตัวละครยืนที่ **ตำแหน่งแลนด์มาร์ก** (ไม่ใช่ตำแหน่งจริง) — Inspect, LFG, High-Five ได้ |
| คนแปลกหน้า ระหว่างทาง | **จำนวน** คนต่อช่อง Geohash-6 เท่านั้น ("👥 12 Walkers") ดีเลย์ 5 นาที |

- Geohash precision 6 (~1.2 × 0.6 km) สำหรับ subscription, precision 7 สำหรับ presence
- High-Five: ที่แลนด์มาร์กเท่านั้น + ต้องกดยอมรับทั้งสองฝ่าย → +5% EXP 15 นาที
- Ghost Mode: ซ่อนทั้งหมด แต่ไม่ได้ High-Five/คำเชิญจากคนแปลกหน้า
- ตำแหน่งจริงของคนแปลกหน้า **ไม่ออกจากเซิร์ฟเวอร์เด็ดขาด**

## 13. Mercenary (ระบบหลัก)
- ลงทะเบียนตัวละครตัวเองเป็นทหารรับจ้าง → สำเนา snapshot ของ Build/ชุด ให้ AI ควบคุม
- คนอื่นจ้างเติมปาร์ตี้ได้ (ค่าจ้างเป็น Gold → เจ้าของได้ 50%, อีก 50% หายไปจากระบบ = gold sink)

## 14. เศรษฐกิจ
- ร้านค้า NPC (ราคาคงที่) + **ตลาดกลางฝากขาย** ใช้สูตรจาก PDF 7.2 เมื่อผู้เล่นมากพอ (Phase 3)
- ค่าธรรมเนียมตลาด 5% = gold sink
- Gold sinks: ซ่อม, ค่าจ้าง Mercenary, ค่าธรรมเนียม, โฉนด, ปรุงยา
- สภาพอากาศ (OpenWeatherMap) ตาม PDF 7.1 — ยกเว้นโบนัสกลางคืน (ดูข้อ 11)

## 15. เทคโนโลยี
```
apps/game         Phaser 3 + TypeScript + Vite (PWA)          → Vercel/Netlify
packages/shared   กฎเกม + ข้อมูล (ใช้ร่วมทั้ง client และ server)
supabase/         Postgres + PostGIS, Auth, Realtime, Edge Functions (server-authoritative)
tools/osm         script ดึง OSM เชียงใหม่ → 8-bit tilemap + landmarks (static)
```
- ขยายจังหวัดใหม่ = รัน `tools/osm` กับ bounding box ใหม่
- Scale: Supabase Pro รองรับหลักหมื่นคน ถ้าเกินค่อยแยก Realtime server

## 16. กฎหมาย / ความปลอดภัย
- PDPA: ขอ consent ตำแหน่ง, **ไม่เก็บ log พิกัดดิบเกิน 7 วัน**, ลบบัญชีได้
- คำเตือนก่อนเล่นทุกครั้ง: ระวังรถ, อย่าบุกรุกพื้นที่ส่วนบุคคล
- ผู้เล่นอายุต่ำกว่า 13 ปี: ไม่อนุญาต (ปรับตามนโยบายภายหลัง)
