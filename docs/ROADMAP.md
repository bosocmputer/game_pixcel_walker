## 🧭 ภาพรวมตอนนี้

**เริ่มงานเครื่องใหม่:** `git pull` → `npm install` → `npm run dev:lan` (มือถือเข้า `https://<ip เครื่อง>:5173`)
งานภาพต้องมี Python 3 + `pip install pillow` แล้วรัน `python pixel-art/<ชื่อ>/build.py` (รายการคำสั่งอยู่ใน README)

**ข้อควรรู้ก่อนแก้โค้ด**
- ตัวเลข/กติกาทั้งหมดอยู่ `packages/shared` (มีเทสต์ 90 ข้อ) — UI/ฉาก Phaser แค่แสดงผล
- ภาพ pixel ทุกชิ้นมีต้นฉบับเป็น `pixel-art/*/build.py` ห้ามแก้ PNG ตรง ๆ · ชุดบนตัวละครวาดด้วยโค้ดใน `apps/game/src/game/gear.ts`
- เพลงอยู่ `apps/game/src/game/music.ts` (เขียนเป็นชื่อโน้ต) · เสียงเอฟเฟกต์ `game/audio.ts` · เอฟเฟกต์สกิล `scenes/battleFx.ts`
- ไฟล์บางไฟล์ใช้ CRLF บางไฟล์ LF — ถ้าให้ agent แก้ด้วยสคริปต์ ระวังอย่าให้ทั้งไฟล์เปลี่ยน line ending (diff จะบวม)
- repo เป็น public แต่สไปรต์ตัวละครยังเป็น prototype จากเกมอื่น → **ห้าม deploy สาธารณะ** จนกว่าจะวาดของแท้

**แนะนำงานถัดไป (เรียงตามความคุ้ม)**
1. ทดสอบจริงบนมือถือหลายเครื่อง (ปาร์ตี้/ดันเจี้ยน/ร้าน/เสียง) แล้วปรับสมดุลเงิน-ของ
2. ใช้ของดรอปเป็นวัตถุดิบ: หม้อปรุงยาในบ้าน (ปุ่มมีแล้ว ขึ้น "เร็ว ๆ นี้")
3. แสดง HP สมาชิกปาร์ตี้ · จำกัดช่องกระเป๋า · ไอคอนสกิลมอนสเตอร์/ธาตุ (ยังเป็นอีโมจิบางจุด)
4. Phase 1: บัญชี + เซฟบนเซิร์ฟเวอร์ + ให้เซิร์ฟเวอร์ตัดสินรางวัล/การซื้อขาย

## 🗺️ ถัดไป (เรียงตามความสำคัญ)

### กราฟิก & สไปรต์ (32-bit / HD-2D Transition)
0. เครื่องมือ: skill **pixel-art-studio** ติดตั้งในโปรเจกต์แล้ว (`.claude/skills/`) ใช้ทำงานข้อ 1–2 และไอคอนไอเทม
1. **Original Avatar Pack**: วาด Base Mannequin, หน้าตา, และทรงผมชุดแท้ของเกมขนาด 48×64 (ปัจจุบันใช้ Prototype Asset จาก Sword of Convallaria สำหรับทดสอบภายใน)
2. ~~Dedicated Monster Pack~~ ✅ ทำแล้ว (`pixel-art/monsters`)
3. ~~Equipment / Outfit Layering~~ ✅ ทำแล้ว (`game/gear.ts`) — ถ้าได้ภาพหุ่นของแท้ layout เดิม ระบบนี้ใช้ต่อได้เลย แต่ถ้าอยากได้ชุดวาดมือละเอียดกว่านี้ ค่อยเพิ่มเป็นเลเยอร์ PNG ต่อเฟรม

### Phase 1 — ออนไลน์จริง (ต้องมีก่อนเปิดให้คนนอกเล่น)
1. **บัญชีผู้ใช้ + เซฟบนเซิร์ฟเวอร์** (แผนเดิม: Supabase Auth + Postgres) — ตอนนี้ล้างเบราว์เซอร์ = ตัวละครหาย
2. **Server-authoritative**: เซิร์ฟเวอร์สร้าง stat จากบัญชีเอง + รันการต่อสู้เอง (เอนจิน deterministic อยู่ใน `packages/shared` รันบน server ได้เลย) แล้วค่อยแจก EXP/ของ
3. **กันโกงตำแหน่ง**: ตรวจความเร็ว/วาร์ปฝั่งเซิร์ฟเวอร์
4. Deploy: เกม (static) → Vercel/Netlify, presence server → เครื่องที่รัน Node + WebSocket ได้

### Phase 2 — Social ต่อ
- Radar แบบปลอดภัย (คนแปลกหน้าไม่เห็นพิกัดจริง — MASTER_SPEC §12) — **ต้องทำก่อนเปิดสาธารณะ**
- เพื่อน, High-Five, แชทสั้น, Mercenary (เติมช่องปาร์ตี้), บอสโลกแบบ async
- ปาร์ตี้ใหญ่ขึ้น/Raid สำหรับพฤกษาอสูร (แนะนำ 4–8 คน)

### Phase 3 — Depth
- ตลาดกลาง, สภาพอากาศ, บอสเฉพาะเมือง, NPC, Aura เคลื่อนไหว
- UI pixel: ไอคอนดันเจี้ยน, ไอคอนธาตุในสนามทดสอบ (ยังเป็นอีโมจิ), ฟอนต์พิกเซลภาษาไทย (ต้องหา/ทำเอง) · สกิลมอนสเตอร์ยังไม่มีไอคอน
