## 🧭 ภาพรวมตอนนี้

อยู่ระหว่าง **Phase 0 (Fun Proof) → Phase 2 (Social)** แบบเล่นในวง LAN กับคนรู้จัก

เซฟอยู่ใน localStorage ของแต่ละเครื่อง และเซิร์ฟเวอร์เชื่อข้อมูลจาก client

## 🗺️ ถัดไป (เรียงตามความสำคัญ)

### กราฟิก & สไปรต์ (32-bit / HD-2D Transition)
1. **Original Avatar Pack**: วาด Base Mannequin, หน้าตา, และทรงผมชุดแท้ของเกมขนาด 48×64 (ปัจจุบันใช้ Prototype Asset จาก Sword of Convallaria สำหรับทดสอบภายใน)
2. **Dedicated Monster Pack (32–48 px, Boss 64 px)**: วาดมอนสเตอร์ขนาด native เพื่อให้ความหนาแน่นพิกเซลเข้ากับตัวละคร 48×64
3. ~~Equipment / Outfit Layering~~ ✅ ทำแล้ว (`game/gear.ts`) — ถ้าได้ภาพหุ่นของแท้ layout เดิม ระบบนี้ใช้ต่อได้เลย แต่ถ้าอยากได้ชุดวาดมือละเอียดกว่านี้ ค่อยเพิ่มเป็นเลเยอร์ PNG ต่อเฟรม

### Phase 1 — ออนไลน์จริง (ต้องมีก่อนเปิดให้คนนอกเล่น)
1. **บัญชีผู้ใช้ + เซฟบนเซิร์ฟเวอร์** (แผนเดิม: Supabase Auth + Postgres) — ตอนนี้ล้างเบราว์เซอร์ = ตัวละครหาย
2. **Server-authoritative**: เซิร์ฟเวอร์สร้าง stat จากบัญชีเอง + รันการต่อสู้เอง (เอนจิน deterministic อยู่ใน `packages/shared` รันบน server ได้เลย) แล้วค่อยแจก EXP/ของ
3. **กันโกงตำแหน่ง**: ตรวจความเร็ว/วาร์ปฝั่งเซิร์ฟเวอร์
4. Deploy: เกม (static) → Vercel/Netlify, presence server → เครื่องที่รัน Node + WebSocket ได้

### Phase 2 — Social ต่อ
- Radar แบบปลอดภัย (คนแปลกหน้าไม่เห็นพิกัดจริง — MASTER_SPEC §12) — **ต้องทำก่อนเปิดสาธารณะ**
- เพื่อน, High-Five, แชทสั้น, Mercenary (เติมช่องปาร์ตี้), บอสโลกแบบ async
- ปาร์ตี้ใหญ่ขึ้น/Raid สำหรับพฤกษาอสูร (แนะนำ 4–8 คน)

### Phase 3 — Depth
- ตลาดกลาง, สภาพอากาศ, บอสเฉพาะเมือง, NPC, Aura เคลื่อนไหว, UI สไตล์ RO (มีดราฟต์ `apps/game/src/ui/_ro-style.draft.css`)

## ❓ เรื่องที่รอตัดสินใจ (คุยกันก่อนทำ)
| เรื่อง | ตัวเลือก | ตอนนี้ |
|---|---|---|
| EXP ตอนสู้เป็นปาร์ตี้ | ได้เต็มทุกคน (มอน HP × n^0.6) / หาร EXP แบบ MMORPG | ได้เต็มทุกคน |
| คูลดาวน์ดันเจี้ยน | ต่อชั่วโมง / ต่อวัน / ใช้กุญแจ | ยังไม่มี |
| ขนาดปาร์ตี้สูงสุด | 3 (ตามเอนจิน 3v3) / ขยายเป็น Raid | 3 |
| Backend | Supabase (ตามแผน) / Node server ของเราเอง | Node presence server (LAN) |
| สไตล์กราฟิก & ขนาดสไปรต์ | 16-bit คลาสสิก (16×16 / 16×24) vs 32-bit HD-2D (ตัวละคร 48×64, มอน 32–64 px) | 32-bit HD-2D (กำลังทำ transition ผ่าน avatar pack) |
| ระบบชุดสวมใส่บนตัวละคร | Modular Equipment Layers (หมวก/เสื้อ/กางเกง) vs Full Cosmetic Outfits | Modular — ทาสีจากรูปร่างหุ่น (procedural) ใช้แล้ว; ชุดวาดมือค่อยเพิ่มทีหลัง |

## 🐞 ปัญหาที่รู้แล้ว
- **สไปรต์ตัวละครปัจจุบันเป็น Prototype Placeholder**: ดึงจาก Sword of Convallaria เพื่อใช้ทดสอบการต่อสไปรต์/อนิเมชัน 48×64 ภายในเท่านั้น และยังเป็นหุ่นตัวเปล่า (ยังไม่มี Layer ชุด)
- **Pixel Density ไม่สม่ำเสมอ (Mixels)**: ตัวละครเป็น 48×64 แต่มอนสเตอร์ยังเป็นสไปรต์ 16×16 ขยายสเกล (32–48 px / 56–64 px) ทำให้ขนาดเม็ดพิกเซลไม่เท่ากัน รอชุด Monster Pack 32–48 px ของจริง
- เคยเจอการต่อสู้ auto เริ่มเองหลังโหลดหน้า 1 ครั้ง ยังจำลองซ้ำไม่ได้
- Presence server ไม่เก็บอะไรลงดิสก์ — รีสตาร์ทแล้วปาร์ตี้หายหมด (ตั้งใจสำหรับช่วง LAN)
